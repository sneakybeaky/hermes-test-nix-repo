# Project Rules

Hermes: when working in this repo, follow these rules.

## Environment Setup

Before doing any work in this repo, check if Nix needs to be bootstrapped.
Only do this when ALL of the following are true:

1. A `flake.nix` OR `devbox.json` exists in the repo root
2. You are running on the sprites terminal backend (check: the hostname
   starts with `hermes-session-`, or `SPRITES_TOKEN` is set in the environment)

If both conditions are met and `nix` is not already on PATH:

```fish
curl -fsSL https://install.determinate.systems/nix | sh -s -- install linux --init none --no-confirm
sudo chown -R (whoami) /nix
set -x PATH /nix/var/nix/profiles/default/bin $PATH
echo 'set -x PATH /nix/var/nix/profiles/default/bin $PATH' >> ~/.config/fish/config.fish
```

Notes:
- This is a Fly.io sprite VM running fish, no systemd, user `sprite`.
- Nix runs root-only single-user with `--init none` — no daemon.
- The install is idempotent — if `nix` is already on PATH, skip it.
- On persistent sprites, Nix survives across sessions on ext4. Reinstall
  only on genuinely new sprites.
- After installing, enter the project devshell with `nix develop` (if
  `flake.nix`) or `devbox shell` (if `devbox.json`).

Do NOT attempt this install on local machines or non-sprite backends.
